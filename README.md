# 🧠 AutomationWithPython

A collection of Python scripts that automate everyday computer tasks — from file handling and text processing to networking and system utilities.  
Each script performs a specific function like generating passwords, organizing files, checking DNS, converting PDFs, or downloading YouTube videos.  

This project is perfect for learning Python automation, improving productivity, and understanding how small scripts can simplify daily tech tasks.

---

## 🔑 Key Scripts

- **password_generator.py** – Creates strong random passwords  
- **organize_files.py** – Sorts and organizes files by extension  
- **dns_checker.py** – Checks and records DNS information  
- **pdf_to_csv.py** – Converts PDF tables to CSV format  
- **web_scrapper.py** – Extracts data from websites  
- **youtube_downloader.py** – Downloads YouTube videos using PyTube
